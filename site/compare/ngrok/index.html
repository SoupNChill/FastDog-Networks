FastDog vs ngrok

ngrok and FastDog both give an app on your machine or server a public HTTPS address through an outbound agent. ngrok is a mature developer tool and API gateway with a free tier. FastDog is a small, flat-priced service for putting a self-hosted app on your own domain.

Short version

  • Pick ngrok for quick sharing and testing on an ngrok address, for webhooks during development, for WebSockets, for TCP and TLS endpoints, or when you want an API gateway with traffic policy, SSO, and enterprise options.
  • Pick FastDog if you have an ordinary HTTP(S) app (no WebSockets, no long or streaming requests, uploads under 50 MiB) and want it on your own domain on a flat monthly price, with no usage meter, connected by your AI assistant with short-lived keys.

Where ngrok is better

  • A real free tier that’s great for quick tests and demos.
  • Long requests and big uploads: no request timeout and no body size limit on HTTP/S endpoints [2], versus our 30 seconds and 50 MiB.
  • Breadth: WebSockets, TCP and TLS endpoints, traffic policy, OAuth/OIDC at the edge, wildcard endpoints, and mTLS [1].
  • Maturity and compliance: SOC 2 Type II, HIPAA, enterprise contracts, and procurement through AWS Marketplace [1].
  • Scale: unlimited endpoints and team features on Pay-as-you-go.

Where FastDog is different

  • Your own domain from $9/mo, without a usage meter. On ngrok, a custom domain starts at the $20/mo Pay-as-you-go plan, plus $0.01 per active hour [1].
  • Built to run all the time, not just for a dev session. The agent runs as a Docker container that restarts by itself.
  • AI setup with safe keys. One-hour, connect-only tokens (the portal prompt), account-scoped API keys that expire (trial and paid plans), and an agent key that’s written to a private file on your server and never shows up in a chat or a command line.
  • Keep your DNS. One CNAME and one TXT at your current DNS host.
