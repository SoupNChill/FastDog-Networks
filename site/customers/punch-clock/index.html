Customer story

Under 30 seconds from DNS record to live HTTPS

22 seconds end to end (timed on a test hostname in a zone on FastDog’s own nameservers, every step run by our operator from scripts). An independent time-keeping app and a FastDog customer. Its domain was registered through FastDog Domains, one hostname is attached with a CNAME, and it serves over HTTPS through the FastDog edge and tunnel.

How we measured: on 2026-10-09 we ran the same attach flow on a throwaway test hostname and timed each step. DNS record to a valid HTTPS response took 22 seconds. Every step was run from scripts by our operator, including the TLS step, which is operator-assisted in Phase 1. Your own time to add a CNAME at your DNS host and start the agent comes on top.

01 / The steps, timed · UTC

Attach flow, 2026-10-09.

  1. 04:31:48.9 · +0.0 s

    DNS record

    CNAME to attach.fastdognetworks.com added; both nameservers answering 8.7 s later.

  2. 04:31:57.6 · +8.7 s

    Attach hostname

    Hostname attachment created (0.9 s).

  3. 04:31:58.5 · +9.6 s

    Verify

    CNAME verified and a hostname-bound agent credential issued (2.8 s).

  4. 04:32:01.3 · +12.4 s

    Run agent

    Agent started beside a test origin and connected outbound to the edge (within 4.0 s).

  5. 04:32:05.3 · +16.4 s

    Operator TLS step

    Site block added on the edge, validated, and reloaded (1.1 s).

  6. 04:32:11.2 · +22.3 s

    HTTPS live

    Let’s Encrypt certificate obtained; a request from outside the edge returned 200 with a valid certificate (4.8 s).

The test hostname, its DNS record, credential, certificate, and agent were removed afterwards.

02 / What was set up

Hostname attach. DNS kept in place.

The customer’s app hostname is a CNAME to attach.fastdognetworks.com. The domain’s nameservers were not moved to FastDog.

CNAME recordapp.usepunchclock.com. CNAME attach.fastdognetworks.com.

The app serves over HTTPS through the FastDog edge and tunnel, and its www hostname redirects to the app.

Elapsed time for this customer, registration to HTTPS on the edge: 11 h 12 min (05:32 → 16:44 UTC, 2026-10-08). Most of that was overnight, before the hostname was attached.
