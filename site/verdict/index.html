01 / How it works

Ask before forwarding.

For each request on an opted-in hostname, the edge asks Verdict for a decision.

Allow
Continue to the origin.
Challenge
Serve a self-hosted proof-of-work page.
Block
Stop the request at the edge.

If the decision service is unavailable, Verdict fails open by default. Shadow mode lets you see would-be decisions before enforcing.

02 / On our edge

A local decision path.

Verdict runs on the edge server itself, so each decision is a local call, not a trip across the internet.
