Verdict / Documentation

A decision for every request.

Verdict is FastDog’s threat decision service for signups, requests, and sessions. Send signals; get allow, challenge, or block, with confidence and a reason.

Decide API

curl -sS http://127.0.0.1:8080/v1/decide \
  -H 'Authorization: Bearer KEY' \
  -H 'Content-Type: application/json' \
  -d '{"ip":"203.0.113.8","path":"/login",
       "method":"POST","signals":["headless"]}'

KEY is a placeholder. The real API key lives at /etc/fastdog/verdict.env on the edge. Never print it or include it in docs or logs.

Edge mode

Use forward_auth with GET /v1/edge-auth to check traffic before it reaches your app. The local endpoint uses forwarded request headers; no Bearer key is required.

200 allow
Pass the request through.
401 challenge
Route the browser to the returned Location for verification.
403 block
Deny the request.
