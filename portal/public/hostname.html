Start with the address people will use to visit your website. You can keep the company that manages your domain.

What's this?
Website address (hostname)
An address such as app.example.com. Use a domain you own.
CNAME record
It points your address at FastDog.
TXT record
It proves you own the domain.
DNS changes
DNS is your domain’s address book. Changes take time to spread: minutes, sometimes up to a few hours.

For example, app.example.com. A pasted web link will be reduced to its address.

Add these two records in your domain provider’s DNS settings. Copy each name and value exactly. Keep both records in place.

Connect your server

This command connects your server to FastDog. It contains a private access key and is shown only once. Save it securely now. Run it on the server where your app runs.
