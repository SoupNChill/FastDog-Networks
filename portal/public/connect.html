Connect your server

Connect the server where your website runs to FastDog.

What are an origin and a tunnel?

An origin is the computer or server where your website actually runs.

A tunnel is a secure outbound connection from your server to FastDog, so you don't open any ports.

First, add your website address and DNS records. Add your website address

What happens next?

DNS records tell the internet where to find your website. We’ll help you add them and check that the address belongs to you.

  1. Verify your website address.
  2. Choose how to run the connection software on your server.
  3. Copy your command, run it, and check for “Server connected”.

Run the connection software

Keep this command private. It contains your connection key and is only shown here once.

Before running it, ask support for the two FastDog connection addresses and your website’s local address. Replace the placeholders in angle brackets. Both FastDog addresses must point to the same service.

How do I know it worked? This page will say “Server connected”. Then open your website below to check that it loads securely.
